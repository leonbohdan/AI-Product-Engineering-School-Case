# ADR-0001: Архітектура Agent Skill: детермінований CLI-оркестратор проти динамічної кодогенерації

- **Статус:** `Accepted`
- **Дата:** 2026-09-26

---

## 1. Контекст та постановка проблеми

У рамках кейсу необхідно розробити інструмент для AI-агентів у форматі [Agent Skills](https://agentskills.io/specification). Цей інструмент допомагає продуктовим лідерам аналізувати перегляди статей у Wikipedia для валідації попиту на теми та нові мовні ринки.

Вимоги кейсу чітко зазначають:
1. Навичкою має бути зручно й ефективно користуватися агенту на **швидкій і недорогій моделі (наприклад, Claude Haiku 4.5 або безкоштовних моделях OpenRouter)**.
2. Одного лише Markdown-файлу з інструкціями або вимогою до агента щоразу писати код з нуля — **недостатньо**.
3. Навичка має містити власний код, що виконує змістовну частину роботи з даними.

Постає архітектурне питання: **у якій формі організувати виконання роботи з даними для AI-агента?**

---

## 2. Критерії ухвалення рішення (Decision Drivers)

- **Споживання токенів та вартість:** Мінімізація обсягу переданих даних у контекст LLM.
- **Точність обчислень (Детермінованість):** Усунення галюцинацій та арифметичних помилок при розрахунку темпів зростання (YoY), ковзних середніх та перцентилів.
- **Сумісність з легкими моделями (Haiku):** Модель має отримувати лаконічну структуру з високим рівнем семантичної інформації, а не 730+ точок сирого JSON.
- **Стандартизація та автономність:** Дотримання відкритого стандарту [Agent Skills](https://agentskills.io/specification).

---

## 3. Розглянуті альтернативи

### Варіант А: Чистий чат-бот / Промпт (Gems, Custom GPT) без локальних скриптів
- **Опис:** Створення промпту з інструкціями; агент робить HTTP-запити самостійно або очікує вхідних даних від користувача.
- **Мінуси:** Суперечить обов'язковій вимозі завдання; відсутній доступ до локальної файлової системи для генерації PDF; модель галюцинує на великих масивах чисел; критично забиває контекст.
- **Оцінка:** *Відхилено.*

### Варіант Б: Динамічна кодогенерація (Code Interpreter / Write-on-the-fly)
- **Опис:** `SKILL.md` містить інструкції, як писати скрипт на Python, а агент кожного разу створює та запускає новий одноразовий скрипт через bash.
- **Плюси:** Максимальна гнучкість запитів.
- **Мінуси:** Нестійкість на легких моделях (Haiku часто робить синтаксичні помилки або використовує застарілі ендпоінти API); витрати сотень токенів на генерацію коду при кожному кроці; довгий час відгуку.
- **Оцінка:** *Відхилено.*

### Варіант В: Детермінований модульний CLI-оркестратор на Python (Обрано)
- **Опис:** Навичка містить готові параметризовані скрипти та єдиний CLI-інтерфейс (`run.py`), який агент викликає однією командою:
  ```bash
  python run.py --topic "Intermittent fasting" --langs "pl,cs" --years 2 --pdf
  ```
  Скрипт самостійно викачує дані, проводить фільтрацію ботів, рахує аналітику, генерує графік і PDF, а в `stdout` повертає **компактний JSON-агрегат** для відповіді користувачу.
- **Плюси:** 100% точність розрахунків; зниження витрат токенів на 90%+; швидкість виконання; ідеально підходить для дешевих моделей; повна відповідність стандарту Agent Skills.
- **Мінуси:** Потрібно заздалегідь спроєктувати та протестувати всі параметри CLI.
- **Оцінка:** *Прийнято.*

---

## 4. Обране рішення

Прийнято **Варіант В**. Створюється модульний пакет на Python у директорії `skills/wikipedia-trend-analyzer/`:
- `run.py` — CLI-оркестратор (точка входу для інструментів агента).
- Модулі в `scripts/`: викачування з Wikimedia REST API, аналіз трендів, генерація візуалізацій та PDF.
- `SKILL.md` — інструкція, що описує аргументи CLI, структуру поверненого JSON та правила інтерпретації метрик для користувача.

---

## 5. Наслідки та компроміси

- **Позитивні:**
  - Навіть легкі моделі (Claude Haiku 4.5, Llama-3-8B) безпомилково взаємодіють з навичкою.
  - Точні дані без галюцинацій у цифрах переглядів і відсотках зростання.
  - Агент отримує готовий шлях до згенерованого PDF для надсилання користувачу.
- **Компроміси / Недоліки:**
  - Потрібна підтримка відтворюваності середовища (`requirements.txt`).
  - Для нових нестандартних типів аналізу потрібно розширювати прапорці CLI.
