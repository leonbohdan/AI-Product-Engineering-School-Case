# ADR-0004: Стек візуалізації та генерації односторінкового PDF-звіту

- **Статус:** `Accepted`
- **Дата:** 2026-09-26

---

## 1. Контекст та постановка проблеми

Згідно з вимогами завдання:
> *«...генерувати графіки та формувати короткі звіти, якими можна поділитися, наприклад PDF на одну сторінку.»*

Односторінковий PDF (Executive One-pager) — це фінальний артефакт для засновників B2C-продуктів та CPO, що містить:
1. Заголовок, тему дослідження та мовні ринки.
2. Ключові метрики (обсяг, YoY приріст, індекс довіри).
3. Графік динаміки переглядів (згладжений тренд).
4. Короткі продуктові рекомендації та ризики.

Необхідно обрати інструменти для генерації графіків та формування PDF, що відповідатимуть обмеженням простоти встановлення, швидкості та надійності розгортання.

---

## 2. Критерії ухвалення рішення (Decision Drivers)

- **Гарантія формату 1 сторінки:** Макет ніколи не повинен «вилазити» на другу сторінку через різницю у шрифтах чи рендерингу.
- **Відсутність важких системних залежностей:** Уникнення необхідності встановлювати браузер Chromium, сервери рендерингу чи складні системні C-бібліотеки.
- **Швидкість:** Генерація артефакту має займати до 1–2 секунд.
- **Якість візуалізації:** Чіткі графіки з правильними підписами осей, легендою та адаптацією під друк/перегляд на екрані.

---

## 3. Розглянуті альтернативи

### Варіант А: Headless Chromium + Playwright / Puppeteer (HTML -> PDF)
- **Опис:** Верстка звіту на звичайному HTML/CSS і друк у PDF через запуск Chromium.
- **Плюси:** Дуже проста верстка на Flexbox/CSS Grid.
- **Мінуси:** Величезний розмір залежностей (Chromium важить 300+ МБ); високий шанс падіння в CI або на машинах без графічних бібліотек (libnss, libasound); довгий запуск (3–5 секунд).
- **Оцінка:** *Відхилено.*

### Варіант Б: WeasyPrint (HTML+CSS -> PDF через Python)
- **Опис:** Python-бібліотека для перетворення HTML+CSS у PDF.
- **Плюси:** Зручна верстка на HTML/CSS.
- **Мінуси:** Вимагає встановлення системних пакетів `cairo`, `pango`, `gdk-pixbuf`. Якщо вони не встановлені в ОС, бібліотека падає з `OSError`. Це порушує вимогу простої відтворюваності середовища через `pip install`.
- **Оцінка:** *Відхилено.*

### Варіант В: Matplotlib (графіки) + ReportLab Platypus (PDF) (Обрано)
- **Опис:**
  - `matplotlib`: побудова графіків динаміки у фоновому режимі (бекенд `Agg`), збереження в оптимізований PNG або SVG.
  - `reportlab`: чистий Python-пакет без жодних системних бінарних залежностей. Використання структурованого рушія верстки `Platypus` (Page Layout and Typography Using Scripts).
- **Плюси:**
  - Встановлюється через чистий `pip install reportlab matplotlib`.
  - Працює на 100% однаково на Linux, macOS та Windows.
  - Жорстко фіксовані розміри блоків та відступів гарантують, що звіт завжди строго займає **рівно 1 сторінку (формат A4)**.
  - Миттєвий рендеринг (< 0.5 с).
- **Мінуси:** Верстка кодом вимагає більше уваги до координат та стилів, ніж HTML/CSS.
- **Оцінка:** *Прийнято.*

---

## 4. Обране рішення

1. **Модуль візуалізації (`scripts/chart_generator.py`):**
   - Використовує `matplotlib` з бекендом `matplotlib.use('Agg')` (headless).
   - Відображає реальні точки, 30-денне згладжування та підсвічує знайдені спайки.
2. **Модуль збірки PDF (`scripts/pdf_generator.py`):**
   - Використовує `reportlab.platypus.SimpleDocTemplate` з розміром сторінки A4.
   - Компонує блоки:
     - Header (Лого/Назва теми, дата генерації, мови).
     - Key Metrics Summary Table (KPI cards).
     - Графік тренду.
     - Section "Key Takeaways & Product Recommendations".
     - Section "Assumptions & Limitations" (чесність щодо обмежень даних Вікіпедії).

---

## 5. Наслідки та компроміси

- **Позитивні:**
  - Проста та безпроблемна інсталяція середовища без помилок бінарних бібліотек.
  - Завжди акуратний, професійний односторінковий документ, готовий до відправки стейкхолдерам.
- **Компроміси:**
  - Зміна стилів або шрифтів потребує налаштування через код ReportLab StyleSheet, що повністю компенсується надійністю.
